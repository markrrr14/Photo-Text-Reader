Introduction

Photo Text Reader is a Flutter and Dart web application designed to convert words visible in photographs into editable digital text. Manually retyping text from photographed notes, printed documents, signs, or learning materials can be time-consuming. The application allows users to select an image, recognize the text using optical character recognition (OCR), review or correct the result, and copy or download the extracted text.

Project Overview

The submitted project is named phototextreader. Its Flutter interface is implemented in main.dart and home_screen.dart, while OCR operations are separated into service files. The application provides an image upload area, language selection, recognition progress, an editable results field, a word and character count, and actions to copy, download, or clear text.

Recognition is performed in the Chrome browser through Tesseract.js 5.1.1, loaded from a content delivery network by web/index.html. Image selection uses the Flutter image_picker package. The browser-based implementation does not send the selected photo to an application server, although internet access is needed to obtain the OCR engine and language data initially.

Scope and Limitations

The supplied source supports OCR in Flutter Web. Its non-web service implementation explicitly reports OCR as unsupported; therefore Android and Windows OCR functionality must not be assumed. The source provides 16 selectable OCR languages, a 25 MB image-size limit, and text-file export. Recognition accuracy depends on image quality, language selection, and the OCR engine. No completed runtime test evidence was supplied with the ZIP.

How It Works

The user opens the Photo Text Reader interface in Chrome and chooses an image from the gallery or file picker. The application reads the image bytes, checks the 25 MB limit, displays the image preview, and starts extraction. The user may select a recognition language and run extraction again. The browser loads Tesseract.js, processes the image, and sends

Narrative Flow of Data

The selected image remains in the browser workflow. Flutter reads the file into bytes and converts it to a base64 data URL for the JavaScript OCR function. Tesseract.js returns recognized text to the Dart interface, which displays it for editing. Copying uses the clipboard; downloading creates a browser-side text file. The source does not implement a database or a user account system.

Conclusion

What the Source Implements

The submitted Flutter/Dart project contains a browser-based workflow for selecting a photo, performing Tesseract.js OCR, displaying editable recognized text, showing processing progress, counting words and characters, and copying or downloading text. These are findings from source inspection, not proof of successful execution on a particular computer.

Limitations

OCR is explicitly unsupported on non-web platforms in the supplied service stub. Initial OCR engine and language-data loading depends on network access. Image size is limited to 25 MB, and poor-quality images may produce recognition errors. The project does not include documented completed functional tests or a server-side storage system.

Recommendations

Recommended improvements include testing with different image qualities and languages, recording recognition accuracy and time, improving user-facing error guidance, and evaluating future offline engine packaging or native-platform OCR support.
